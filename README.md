Movie Database Application
This project is a simple Movie Database Management System that allows users to perform basic CRUD (Create, Read, Update, Delete) operations on movie records. It provides an intuitive interface to manage a collection of movies, using MySQL as the database for data storage and Python as the backend language, integrated with Visual Studio.

Key Features:
Create: Add new movie records with details such as title, genre, release date, and description.
Read: View the complete list of movies, as well as search for movies by title or genre.
Update: Edit movie details, including title, genre, and release year.
Delete: Remove a movie record from the database.
The system connects the frontend to the MySQL backend through Python, ensuring smooth interaction with the database and handling user inputs efficiently.

Technologies Used:
Backend: Python (Flask)
Database: MySQL
Frontend: HTML, CSS
IDE: Visual Studio

Database Structure:
The movie database stores movie records with the following attributes:
ID: Unique identifier for each movie (Primary Key).
Title: Name of the movie.
Genre: Category or genre of the movie (e.g., Action, Drama, Comedy).
Release Date: The date the movie was released.

Installation & Setup:
Clone this repository to your local machine.
Install the necessary dependencies, such as Flask or Django, and MySQL.
Set up the MySQL database and import the schema provided in the project.
Configure the backend to connect to your local or remote MySQL database.
Run the application using Visual Studio.

Usage:
Once the application is set up, you can access it through your browser and use the interface to add, view, update, and delete movie records.
